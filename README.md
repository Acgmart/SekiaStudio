# 初始化步骤
1.确保安装了.Net8.0  
https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0  
2.编辑器工具生成代码  
ET/Init/InitAll  
3.生成资源  
YooAsset/AssetBundle Builder/Click Build  
BuildPipeline：ScriptableBuildPipeline  
CopyBuildinFileOption : ClearAndCopyAll  
4.打包  
ET/Loader/Build Tool/BuildPackage  
输出路径：ET/Release
