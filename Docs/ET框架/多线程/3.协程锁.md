# 协程锁CoroutineLockComponent
协程锁组件用于事件排序执行，组件层级：
Root-CoroutineLockComponent-CoroutineLockQueueType-CoroutineLockQueue-CoroutineLock
CoroutineLockQueueType用于区分事件类型，比如加载资源
CoroutineLockQueue用于区分具体的事件，比如要加载的资源地址

# 排序机制
相同任务会生成对应数量的await CoroutineLock，这个锁需要组件内部SetResult才能解。
前面的CoroutineLock在Destroy方法调用下一个锁的解锁逻辑(WaitCoroutineLock)，形成逐一解锁。
通过CoroutineLockComponent的Update方法实现一帧内遍历所有解锁逻辑队列。
如果队列长度超过100或者执行时间超时则日志警告，队列太长可能爆栈。
如果下一个锁不存在则重置队列。
