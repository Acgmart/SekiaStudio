# 指定上下文
这里讨论async/await任务链中传递的上下文，即GetContextAsync方法如何获取上下文。
在异步方法前都需要指定上下文，没有的话就传递空：
StartAsync().NoContext();
这里的上下文即异步任务执行过程中依赖于外部提供的参数。

# 通俗解释
线程执行到了第一个await，挂起状态机：
    1.将第一个await之后的代码都包装为MoveNext方法
    2.将状态机交给同步上下文线程(ThreadSynchronizationContext.Post)
    3.继续执行await外的代码，即同步部分，如NoContext()和之后的代码。
状态机由线程池中的随机线程开始执行AwaitUnsafeOnCompleted和MoveNext方法循环。

# 获取上下文
AwaitUnsafeOnCompleted方法和SetContext方法形成了Task链，共享上下文。
由WithContext为ETTask.Context赋值的上下文，可以直接传递到子Task。
    就算WithContex是延迟执行的也能通过SetContext中的循环遍历所有子Task。
GetContextAsync方法中创建的TaskType为ContextTask，可以直接返回Contex对象。
这里的Contex对象必须是WithContext传入的类型。

# ObjectWait组件的Wait方法
异步方法的上下文大体有3种情况：无上下文、简单的取消操作上下文、复杂的自定义上下文。
对于大多数情况都是无上下文或者简单取消，比如移动可以在当前位置终止。
用ObjectWait组件的Wait方法可以强制等待任务完成or提前取消。
    通过Notify方法是完成任务后主动解锁
    通过ETCancellationToken是任务提前取消
    如果ETCancellationToken为空即无上下文，也不用担心报错。
